## 🛠️ Architecture Setup
* **`/src/config.py`**: Declares formal abstract typing specifications for nested AI tool structural calls.
* **`/src/main.py`**: Executes model routing orchestration, catches billing exceptions, and spins up a local FastAPI server interface.
* **`/evals/run_evals.py`**: Runs analytical assertions verifying string lineage and numeric threshold bounds.

## 🚀 Quick Start Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Run the evaluation metrics engine:**
   ```bash

   ```
